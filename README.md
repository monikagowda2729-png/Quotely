# 📖 Quotely

> **Discover. Save. Share. Inspire.**

Quotely is a modern and user-friendly quote discovery app built with **React Native and Expo**. It helps users discover meaningful quotes, explore them by category, save their favorites, and revisit their quote history.

## ✨ Features

* 💬 Discover inspiring quotes
* 🏷️ Explore quotes by category
* ❤️ Save favorite quotes
* 📚 View previously discovered quotes
* 🔄 Get a new quote whenever you want
* 📱 Clean and responsive mobile UI
* ⚡ Built with React Native and Expo

## 🛠️ Tech Stack

* **React Native**
* **Expo**
* **TypeScript**
* **Expo Router**
* **JavaScript / TypeScript**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/monikagowda2729-png/Quotely.git
```

### 2. Navigate to the project

```bash
cd Quotely
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the Expo development server

```bash
npx expo start
```

You can then open the application using:

* **Expo Go**
* **Android Emulator**
* **iOS Simulator**
* **Web Browser**

## 📱 Running the App

After running `npx expo start`, scan the QR code using **Expo Go** on your mobile device, or press the appropriate key shown in the terminal to launch an emulator or web browser.
